# 过程曲线方法

## 输入与质量检查

一条曲线对应一个明确工艺过程。检查每条曲线的 TG、工站、曲线类型、阶段、单位和判定是否一致；禁止跨过程合成一条曲线。时间列定义是开始、结束还是采样时间需写入数据描述。

按 `sample_index` 排序；曲线轴可能往返，因此不能直接按 x 排序掩盖路径。对压装推进、卸载、回程及拧紧阶段分别处理。缺失点、重复采样、截断及饱和值应报告数量；显著数据问题的曲线单列，不静默删除。

## 对齐

- 起点对齐：`x_aligned = x - x_first`，保留原始起点。
- 接触点对齐：优先设备给出的接触点；使用力／扭矩阈值推测时，阈值和连续点要求来自配置并记录为推测点。
- 仅在同阶段、同单位的共同 x 区间内插值，不外推。没有共同区间则报告不可比较。
- 接触点偏移本身可能是失效特征；不能通过对齐将该异常完全抹去，应同时报告原始偏移。

## 特征与分组

峰值、峰值位置、终点、区段斜率、曲线面积、波动、异常段长度等按分析目标选取。积分定义必须与轴单位一起保存；力–位移面积单位可能为 N·mm，不可直接称为 J。

按 OK／NC、批次、供应商、班次、变化前后比较时，先确保过程条件和型号可比，报告每组曲线数和独立 TG 数。大量采样点不是大量独立工件，不能把点数当统计样本量。

参考包络可基于合格组的分位区间；有实测规格时另画规格边界。受污染或过少的合格样本不能形成可靠参考。异常区段描述为超出参考范围的连续区间，不能直接宣布机械结构损坏。

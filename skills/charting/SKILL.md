# 图表制表

输入为数据变量引用、图表所回答的问题以及字段／分组。读取 preview 理解数据结构，图表工具直接读取全量表格，不把完整数据嵌入提示词。

## 制图流程

1. 说明图要回答的业务问题，确认 x／y、分组、单位和聚合粒度。时序数据先排序，不同单位不放在同一数值轴上。
2. 通过 `chart.create(variable, kind, x, y, group)` 调用 HOST 已注册类型；未知种类先检查能力，不能凭空生成工具名。
3. 制图前需要分组计算时，在当前批准节点范围内调用 Python；若新增独立技能级计划则先提请确认。
4. 产物包含标题、轴名及单位、数据来源变量和版本、图例、样本量及必要说明。导出 HTML 所需脚本资源本地化。
5. 检查空数据、常量、异常极值和过密标签；没有数据时给出原因，不画看似正常的空趋势。

## 选图规则

| 问题 | 图形与补充 |
| --- | --- |
| 是否突然升高或持续恶化 | 不良率时间线，同时保留投入量／检测量和 NC 数 |
| 批次或供应商是否更差 | 分组不良率和样本量，连续参数使用箱线图／分位数 |
| 开班分布 | 按班次首小时分组柱图，明确是 NC 构成还是风险 |
| 曲线哪个区段不同 | 同轴曲线叠加、组内参考范围与异常段标记 |
| 哪个参数贡献最多 | 参数频次条图，区分 NC 事件数和不良 TG 数 |

颜色保持一致：同一分组在多图中保持同色，NC 使用清晰且克制的强调。标题描述实际指标，不用“根因图”等超过证据的名称。

现有图表程序通过 `developer-skills/migrate-agent-tool` 包装为标准图表接口；不因迁移重复重写其已验证的渲染逻辑。图表是展示产物，原始表格和统计代码必须可以追溯。

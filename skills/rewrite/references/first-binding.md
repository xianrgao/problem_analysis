# 首次有效绑定与一对多关联

1. 在日志来源层按 TG、零件、安装位置过滤；保留事件 ID、事件时间、操作类型和批次／供应商。
2. 按已确认的“首次有效绑定”定义选择记录：若系统记录解绑、撤销或重放，需要先用事件 ID 去掉明确重复事件，再应用有效性规则。不能将任意最早文本日志直接认作有效装配。
3. 先比较时间，遇到相同最早时间且不同批次／供应商时生成冲突清单。不能根据字母排序或文件顺序取第一条。
4. 如果用户调查“最初装配”，保留首次绑定，即使后续改绑；若调查“检测时在装配件”，改为检测时点的有效绑定，需要修订数据口径。
5. 多零件／位置用可读前缀列名，例如 `bearing_left_batch`、`bearing_right_batch`；输出一行一 TG 的补充表，再按 TG 左关联 NC。前缀规则保存到描述或元数据。
6. 输出必须包含未匹配清单、冲突清单和匹配覆盖率。原始绑定日志保留为独立变量，方便追溯。

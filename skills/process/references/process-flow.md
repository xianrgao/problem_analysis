# 过程流程（模拟）

`OP10 零件上线与首次绑定 → OP20 轴承压装 → OP30 螺栓拧紧与下线`

工件 `workpieces.tg` 关联多条 `visits`；过站记录关联 `stations`；每次过站可有多条 `measurements`；检测可以关联多条 `nc_events`。统计不良 TG 需要显式去重，返工会改变过站次数，不能用过站行数代替工件数。

上线时间来自 `workpieces.launched_at`，检测判定来自 measurements，NC 时间来自 `nc_events.occurred_at`。这三个时间用途不同。

模拟相邻工站滞留按进入／离开时间与过程顺序判断；`>4 小时` 提示长间隔，需要继续区分停产、计划离线、返工或物流等待。真实工艺存在分支或回流时，应建立路由版本及实际序列，不按站号字典顺序推断。

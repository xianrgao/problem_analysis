# 证据与结论边界

每条关键结论关联实际变量名与版本、生成节点、筛选范围和统计代码；面向用户可展示可读证据名称，详情保留技术引用。

| 结论类型 | 可以表述 | 不能替代的证据 |
| --- | --- | --- |
| 描述事实 | 该范围 120 个不良 TG 中，102 个绑定批次 B | 同期批次投入量及风险 |
| 集中线索 | B 占比 85%，达到配置的集中度阈值 | 根因、供应商责任 |
| 关联 | 相同条件下 B 的观察不良率更高 | 排除混杂或干预验证 |
| 验证支持 | 受控更换或对照试验后，预定义指标按预期改善 | 无限外推至其他工站和时间 |

始终给出分子、分母和去重对象；小样本、零分母、缺失绑定、不同产品混产需要明确说明。零事件不等于零风险。能够计算区间时同时报告区间，不能因单个 p 值宣称工艺因果关系。

趋势前后段需要相同检测方法、规格、单位和采样规则。检测设备或规格变化是候选解释，不应当作普通噪声删除。区分 NC 记录、检测记录、TG、过站次数四种粒度。

结果优先回答用户的业务问题，附上最关键表格或图；不要在最终结论中堆叠所有技术日志。留存已检查但不支持的方向可减少后续重复调查。

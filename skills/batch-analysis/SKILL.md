# 零部件批次号解析

先确定零件、PN、供应商和适用编码版本，再按需读取 [演示编码规则](references/batch-rules.md)。禁止把未知批次套入名称相似的规则。

## 解析与分析

1. 保留原始批次号，输出规则 ID、解析状态和可证明的编码字段；无法识别返回 `unknown_format`，不删除行、不猜供应商。
2. 大表通过 Python 读取实际变量，使用 [scripts/parse_batch.py](scripts/parse_batch.py) 或经过验证的真实规则，保存解析后数据及未识别清单。
3. 按零件／安装位置分别计算去重不良 TG 的批次及供应商分布，同时列出缺失绑定和无法解析的比例。
4. 默认占全部不良 TG 超过 80% 为“强集中线索”，不是已经验证的强因果关系。配置可修改阈值。
5. 要判断风险，必须取得同期 OK／NC 及绑定数据；比较投入量、不良率、参数分布和曲线。大量投入批次的 NC 占比高可能完全由投入量解释。

本技能提供规则与分析口径；需要 data-analysis 或其他技能组成新计划时遵守确认流程。进入已批准批次分析节点时可用内部工具完成解析与统计。

# 批次与供应商比较

先确定投入总体是否覆盖同工站、task／parameter、产品族及时间窗口。NC 明细只能求 NC 中的构成比，不能求批次不良率。

结果至少包括：分组名称、去重投入 TG、去重不良 TG、不良率、缺失绑定量。强集中阈值默认大于 80%，使用配置值；以总 NC TG 为分母并同时给出已成功绑定 TG 为分母的占比，避免通过丢失缺失项夸大集中程度。

连续参数比较展示样本数、中位数、分位区间、均值、标准差和规格来源；偏态或异常值明显时不要只给平均值。工程规格与统计参考范围分开。不同单位或参数定义不得合并。

当正常批次 NC 为零时风险比不可直接相除；报告两个组的原始计数、风险差及区间，必要时使用 Fisher 精确检验。小样本不能凭显著性缺失宣称“两组相同”。

按班次、工站、型号或时间分层是解释混杂的手段，不应无限切分挑选显著结果。后续根因判断仍需过程知识和验证。

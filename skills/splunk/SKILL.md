# Splunk 日志查询

本技能负责日志查询语义，已有 Splunk agent 是实际执行后端。通过 `splunk.query(kind, filters)` 调用，不重新实现一套与现有程序竞争的日志检索器。

## 流程

1. 确定查询类型：首次绑定、设备变化点、质量参数、信号交互、操作记录。查询参数来自用户、已批准节点或输入变量，不猜工站与时间范围。
2. 检查 HOST 中适配器声明的支持类型。未接入的类型返回明确“不支持”，不以其他日志或模拟数据替代。
3. 按 [查询口径](references/query-semantics.md) 提供工站、时间及必要关联条件；大 TG 集合通过变量引用传递给代码端，不串到提示词。
4. 执行查询，由适配器保存结果并返回 `variable_name`、`row_count`、`description` 和宿主版本信息。记录查询条件、时间覆盖、分页完成状态及源系统。
5. 查看自动 preview 验证列结构、时区、结果粒度和缺失；截断或部分失败不能标为完整查询。

对于首次绑定，输出保留 TG、零件、PN、安装位置、批次、供应商、绑定时间、事件 ID；真实字段通过适配器映射。变化点需保留结构／部件、变化类型、时间、前后值及说明，来源没有的字段允许缺失，不能编造。

没有相关日志时输出零行变量及查询范围。对“没有变化点”的结论加上日志覆盖条件；不能直接推导“设备没有变化”或“必须更换备件”。

## 从现有 agent 迁移

代码适配由开发技能 `.cursor/skills/migrate-agent-tool` 完成。保持现有凭据来源、检索语法、分页／重试逻辑和验证过的查询能力；抽出函数或 JSON stdin/stdout 边界，在宿主侧发布变量，最终由本技能指导何时、如何调用。

本技能不持有凭据，不自动部署索引配置，不修改产线日志。

# 现有程序检查清单

| 项目 | 需要确认的内容 | 迁移决定 |
| --- | --- | --- |
| 入口 | 函数名／脚本命令、参数及默认值、是否依赖当前工作目录 | 适配器调用的唯一入口 |
| 依赖 | import 的第三方包与版本、解释器版本、是否需要 Windows 特定组件 | 同环境 `python` 或独立解释器 `script` |
| 鉴权 | 凭据来源（环境变量名、配置文件、凭据管理器）、令牌刷新方式 | 保持原来源，不进入工作台设置展示字段 |
| 输入 | 时间格式与时区、工站／TG 列表规模、分页参数 | 宿主请求字段到原参数的映射 |
| 返回值 | 类型（DataFrame、列表、文件路径、图片）、列名、空结果表示 | 规范化为 rows／data_path／figure |
| 日志 | 打印到 stdout 还是日志文件、是否包含敏感信息 | 脚本模式改到 stderr；敏感内容不外露 |
| 异常 | 抛出的异常类型、部分失败时的返回、重试与超时 | 原样抛出并带来源说明，不静默降级 |
| 副作用 | 是否写数据库、缓存、临时文件，是否修改源系统 | MOS 等数据源只读；临时文件放执行目录 |
| 性能 | 单次耗时、最大行数、并发限制 | 设置 `timeout`，大结果用 data_path |

检查脚本 `scripts/inspect_tool.py` 只做静态分析：列出函数签名、文档、导入、读取的环境变量名称、日志调用、`raise` 与 `return` 位置。环境变量只列名称，不读取值。

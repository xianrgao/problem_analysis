# 开发状态

此文档记录当前源码的实现与验证状态，不能将方案中的功能全部视为已经完成。

## 已写入的模块

- 完整实施计划及前端文案约定。
- Python 工程配置和模块目录；`main.py`／`line-engineer` 命令行入口（`serve`、`init-demo`），服务仅监听 127.0.0.1。
- SQLite 会话基础存储、变量版本及原子发布的表格／preview 对。
- 计划节点校验、循环依赖检查和计划指纹。
- Skill 元数据发现、资源快照和渐进加载。
- 模型 HTTP 接入、Python／脚本适配器及宿主工具基础实现；新增模拟曲线源与 `curves.query` 工具。
- 独立 Python 进程执行及变量读写 SDK。
- 模拟 MOS 五表、模拟 Splunk 和曲线生成器。
- 只读取数、首次绑定、班次／滞留／趋势／批次风险分析，以及过程曲线算法。
- 11 个业务 skill 的正文、工具声明和主要参考资料／脚本。
- 应用容器 `application.py`：存储、技能、连接器、执行器、问题台账、跨会话快照与 CSV／Excel 导入。
- 编排器 `orchestration/engine.py`：
  - 路由、计划生成与修订、绑定会话＋计划＋版本＋指纹的批准、批准时冻结技能快照。
  - 按 DAG 顺序执行与节点检查点；阶段完成后复核并提出下一阶段计划（需再次确认）。
  - 执行中追问：查询进度、范围调整（当前步骤完成后暂停并生成修订计划）、停止。
  - 停止、从检查点恢复、重启后标记中断（不重跑已完成步骤，不恢复已停止任务）。
  - 并行会话调度（默认 2 个，可配置），其余排队。
  - 模型模式的技能内部执行循环：工具声明校验、SQL／代码最多两次自动修复、第一人称进度文案过滤。
- 确定性演示引擎 `orchestration/demo_engine.py`：规则路由与分阶段计划；SQL、Splunk、曲线查询及 Python 计算均通过宿主工具真实执行。
- 后端 API `api/server.py`：会话、消息、计划批准／修订、停止／恢复、事件流（支持 `Last-Event-ID` 补发）、变量分页／预览／导出、导入、快照、问题台账、设置、技能目录，以及预构建前端的静态托管。
- React 工作台组件与样式（`web/src/styles`），执行时间线按步骤聚合：进度说明和状态默认可见，技能、参考资料、SQL、代码与变量预览默认折叠。

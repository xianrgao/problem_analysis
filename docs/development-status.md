# 开发状态

此文档记录当前源码的实现与验证状态，不能将方案中的功能全部视为已经完成。

## 已写入的模块

- 完整实施计划及前端文案约定。
- Python 工程配置和模块目录；`main.py`／`line-engineer` 命令行入口（`serve`、`init-demo`），服务仅监听 127.0.0.1；`serve --open` 在服务就绪后再打开浏览器。
- SQLite 会话基础存储、变量版本及原子发布的表格／preview 对；小表完整预览，预览生成失败时显式标记不可用；事件与消息记录所属对话轮次。
- 计划节点校验、循环依赖检查和计划指纹。
- Skill 元数据发现、资源快照和渐进加载；技能内 `python.execute` 可导入该技能冻结版本的 `scripts/`。
- 模型 HTTP 接入（OpenAI 兼容协议）及自定义模型适配接口（`driver: python`）、Python／脚本适配器及宿主工具：MOS 子 agent 返回实际执行的 SQL，已有图表程序经适配器输出标准图表，`shell.execute` 仅在宿主检测到 PowerShell／Bash 时注册；模拟曲线源与 `curves.query` 工具。
- 独立 Python 进程执行及变量读写 SDK；超时终止进程及子进程，分析解释器可配置，可通过 `executor.factory` 替换为公司隔离执行环境。
- 模拟 MOS 五表、模拟 Splunk 和曲线生成器。
- 只读取数、首次绑定、班次／滞留／趋势／批次风险分析，以及过程曲线算法；班次、开班窗口及各类阈值等经验规则由 `config/rules.json` 配置，可在数据目录的 `settings.json` 中按机器覆盖；曲线配置提供压装力—位移与扭矩—角度两类并可扩展。
- 11 个业务 skill 的正文、工具声明、主要参考资料／脚本及验收样例（`acceptance.json`）。
- 应用容器 `application.py`：存储、技能、连接器、执行器、问题台账、跨会话快照与 CSV／Excel 导入。
- 编排器 `orchestration/engine.py`：
  - 路由、计划生成与修订、绑定会话＋计划＋版本＋指纹的批准、批准时冻结技能快照；文字形式的“确认”不视为批准，需在对应计划卡片上确认。
  - 按 DAG 顺序执行与节点检查点；阶段完成后复核并提出下一阶段计划（需再次确认）。
  - 执行中追问：查询进度、范围调整（当前步骤完成后暂停并生成修订计划）、停止。
  - 停止、从检查点恢复；应用关闭时运行中的任务记为中断，重启后从检查点自动继续（`resume_on_restart`；不重跑已完成步骤，不恢复已停止任务）。
  - 并行会话调度（默认 2 个，可配置），其余排队。
  - 模型模式的技能内部执行循环：工具声明校验、SQL／代码最多两次自动修复、第一人称进度文案过滤。
- 确定性演示引擎 `orchestration/demo_engine.py`：规则路由与分阶段计划；SQL、Splunk、曲线查询及 Python 计算均通过宿主工具真实执行；“刚才的图”对应多张同时生成的图表时先澄清；会话可按编号关联已有台账问题并追加证据。
- 后端 API `api/server.py`：会话、消息、计划批准／修订、停止／恢复、事件流（支持 `Last-Event-ID` 补发）、变量分页／预览／导出、导入、快照、问题台账、设置、技能目录，以及预构建前端的静态托管；离线 HTML 报告含证据链接与数据版本。
- React 工作台组件与样式（`web/src/styles`），执行时间线按步骤聚合：进度说明和状态默认可见，技能、参考资料、SQL、代码与变量预览默认折叠；长表格虚拟滚动；箱线图、直方图在基础图表包中以等效图层渲染。
- 开发技能 `.cursor/skills/author-line-skill`（模板与校验器）和 `.cursor/skills/migrate-agent-tool`（静态检查与契约验证），以及 `examples/adapters` 迁移示例。
- 离线交付：`packaging/build_offline.py` 生成含 Windows x64 wheels、Python 用户级安装包、模拟数据、安装／启动／校验脚本和 `SHA256SUMS.txt` 的离线包；[接口文档](api-contract.md)与[迁移手册](migration-guide.md)。
